# AURA AI

A school-friendly modular Python voice assistant inspired by classic AI assistants.

## Run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run:
   pip install -r requirements.txt
4. Start:
   python main.py

## Example commands
- What is the time?
- What is today's date?
- Open YouTube
- Open Google
- Open calculator
- Open notepad
- Calculate 25 * 18
- Search the web for Python
- Exit

AURA uses speech recognition when a microphone is available and falls back to typed input.
